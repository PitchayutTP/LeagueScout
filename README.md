# LeagueScout

แดชบอร์ดสำหรับค้นหาและเปรียบเทียบนักฟุตบอล
แสดงข้อมูลความสามารถ ศักยภาพ มูลค่าตลาด และผลงานรายฤดูกาล

## Features
- แสดงภาพรวม เช่น จำนวนนักเตะ มูลค่าตลาดรวม และคะแนนเฉลี่ย
- ค้นหานักเตะตามชื่อ
- กรองตามตำแหน่ง ลีก ช่วงอายุ และมูลค่าตลาด
- จัดเรียงนักเตะตามคะแนนความสามารถและศักยภาพ
- แสดงความสามารถด้วยกราฟเรดาร์ และประตู/แอสซิสต์ด้วยกราฟแท่ง
- เปรียบเทียบความสามารถกับมูลค่าตลาดผ่านกราฟแบบโต้ตอบ

## Tech Stack
React, JavaScript, Tailwind CSS, Recharts, React Router, Vite

## Data
โปรเจกต์ Frontend นี้ใช้ข้อมูลนักฟุตบอล 30 คนจากไฟล์ JSON
ไม่ได้เชื่อมต่อข้อมูลสด และการจัดอันดับใช้สูตรคำนวณจากข้อมูลที่มี ไม่ใช่ AI
